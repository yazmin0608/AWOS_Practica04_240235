# AWOS_Practica04_240235
## Sistema de Autenticación Multi-Social con OAuth 2.0 y Tailwind 4.x

### 📝 Descripción del Aprendizaje
En esta práctica aprenderé a implementar un sistema de autenticación robusto y moderno utilizando el estándar **OAuth 2.0**. Los objetivos principales son:
* **Configuración de APIs:** Aprender el proceso de registro y obtención de credenciales en plataformas como GitHub, Facebook, Discord, X y LinkedIn.
* **Middleware de Seguridad:** Implementar **Passport.js** para gestionar el flujo de autenticación y **Express-session** para mantener la persistencia del usuario.
* **Diseño Moderno:** Utilizar **Tailwind CSS 4.x** para crear interfaces responsivas y de alto rendimiento.
* **Consumo de Datos:** Extraer y mostrar información personalizada desde las APIs de redes sociales (nombres, imágenes de perfil y contenido exclusivo).
